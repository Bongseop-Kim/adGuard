# blind 세트 — 개발 중 열람 금지 · 채점기 실행 결과만 확인

> **경고: 탐지기 개발자는 이 폴더(`eval/blind/`)의 어떤 파일도 열어 보지 마세요.**
> 문제·정답·미끼·변형이 모두 들어 있습니다. 채점기 실행 결과(점수와 놓친 건수)만 확인하세요.

## 실행 방법

```
python serve.py
```

- Python 3.10 이상, 표준 라이브러리만 사용 (외부 패키지·CDN 없음). Windows·macOS 공용.
- 진입 URL: `http://127.0.0.1:8190/`
- 다른 도메인(iframe용): `http://localhost:8191/` (serve.py가 함께 띄움)
- 종료: `Ctrl+C`
