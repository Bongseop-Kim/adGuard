불법광고 점검

입력한 주소에서 시작해 하위 페이지, 게시글, 댓글, iframe 안까지 살펴보고 숨겨지거나 변형된 불법광고를 찾습니다.

http:// 또는 https://로 시작하는 주소를 입력하세요.
옵션

상한에 닿으면 그때까지 찾은 결과를 저장합니다.
AI 광고성 판정 (선택) 확인 중
OpenAI API 키(유료 등급)를 넣으면 규칙만으로 애매한 후보를 AI가 한 번 더 판정합니다. 비워 두면 규칙만으로 탐지합니다. 키는 프로그램 폴더의 .env 파일에 저장되며, 메모장으로 그 파일을 직접 고쳐도 됩니다.
결과는 프로그램 폴더에 저장됩니다. result.json(제출 형식), report.html(보고서), result.csv(Excel)
