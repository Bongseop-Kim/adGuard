## 1. 핵심 결론

1. **실행 실패는 전 항목 0점이다.** 안정성이 속도보다 먼저다. 배포는 PyInstaller **onedir**(UPX 끔) + 실행 파일 옆에 둔 Chromium headless shell이다. Edge는 예비로만 둔다 (05).
2. **판정 = (4종 기법 신호) AND (광고성 내용), 같은 요소 안에서.** 행안부 누리집 한 페이지에 정상 숨김 텍스트가 716건 있었다(직접 측정). 클래스 이름으로 거르면 안 된다. 예시 정답이 `span.visually-hidden`이고, 그누보드 스팸도 사이트의 `sound_only` 클래스를 재사용한다 (02, 04).
3. **숨김은 속성 대조가 아니라 "글자가 실제로 그려진 박스"로 판정한다.** 텍스트 노드의 `getClientRects`, 조상 클리핑 교차, 누적 opacity, 조상을 거슬러 계산한 배경과의 WCAG 대비율(1.25 미만)을 본다. 배경이 이미지이면 스크린샷 차분으로 판정한다. `checkVisibility()` 기본값은 display·content-visibility만 본다 (04).
4. **HOMOGLYPH·JAMO는 `skeleton(NFKC(x))` 한 번으로 매칭하고, 기법 코드는 원문 글자로 정한다.** NFKC는 받침과 구분자를 처리하지 못하므로 자모 조합기를 직접 만든다. 한국어 닮은꼴 표는 confusables, 스팸체 생성기, KOTOX 사전(MIT)을 합쳐 만든다 (04).
5. **모든 분석 페이지는 렌더링한다.** 정적 요청은 링크 수집용으로만 쓴다. 속도는 브라우저 1개 + 컨텍스트 4~6개(RAM에 따라)로 낸다. CSS·JS는 막지 않고 이미지·폰트·미디어만 막는다. `networkidle` 대신 `domcontentloaded`를 쓰고 DOM이 잠잠해질 때까지 기다린다. 브라우저는 "탐지 시작" 전에 미리 띄운다 (03, 05).
6. **전자정부 게시판은 상세와 목록 2쪽 이후가 POST다.** 클릭을 가로채서 요청을 수집하지 않으면 글을 하나도 못 연다 (03).
7. **AI는 기본으로 끄고, `.env`에 키가 있을 때만 애매한 후보를 배치로 재판정한다.** 호출당 10초, 전체 60초 예산이고, 넘으면 규칙 기반으로 판정한다 (05).

## 3. 기법 개요 (상세는 04)

| 기법 | 판정 방법 | 주의할 점 |
|---|---|---|
| OFFSCREEN | 글자 박스가 0 크기이거나, 뷰포트·조상 클리핑 영역 밖이거나, 계산된 `font-size` ≤ 1px이거나, `display:none`인 경우 | 요소 박스만 보면 `text-indent:-9999px`를 놓친다. 텍스트 노드 박스로 봐야 한다 |
| TRANSPARENT | 누적 opacity ≈ 0, `color`·`-webkit-text-fill-color`가 투명, `visibility:hidden`, 배경과의 대비율 < 1.25 | 1.1로 잡으면 `#eee`(1.16)와 opacity 0.1(1.25)을 놓친다 |
| 기법 코드 | 색·투명 계열 속성이면 TRANSPARENT, 배치·크기·렌더링 계열 속성이면 OFFSCREEN. 두 계열이 다 걸리면 2건 | |
| HOMOGLYPH | NFKC → confusables skeleton → 한국어 닮은꼴 표로 정규화한 뒤 매칭. 매칭 구간의 원문에 치환된 글자가 있으면 판정 | 전각·키릴로 위장한 브랜드명(`ｍｅｇａ－ＢＥＴ`)은 키워드 사전에 없다. 그래서 **같은 요소에 광고성 내용이 있으면** 판정한다 |
| JAMO | 보이지 않는 문자·구분자 제거 → 자체 조합기로 음절 복원 → 키워드와 자모 단위 편집 거리 비교 | NFKC는 `ㄱㅏㅁ`을 `가ᄆ`으로 잘못 붙인다 |
| 광고성 | 키워드 사전(도박, 성인, **대포통장·법인통장·통장 임대·유심·환전**, 마약, 불법 대출) + 패턴(텔레그램 ID, 가입 코드, 보너스 %, 전화번호) | 정상 공지("불법도박 예방")는 숨김·변형이 없으므로 출력하지 않는다 |
| 숨기지 않은 일반 광고 | 4종이 아니므로 `result.json`에 넣지 않는다. 대신 `result_extra.json`에 ETC로 넣는다 (모집요강의 "게시되거나 숨겨진" 대응) | |

## 4. 탐색 개요 (상세는 03)

- 링크 발견 5단계: DOM 속성 → 주석·JS 문자열 속 URL → `robots.txt`·`sitemap.xml` → `onclick`·POST 클릭 가로채기 → 더보기·댓글 클릭
- 범위는 등록 도메인 기준(go.kr은 Public Suffix List에 있음) + 페이지 안의 모든 iframe
- 정규화는 모집요강 12쪽 규칙과 1:1로 맞추고 `;jsessionid`를 제거한다. 그누보드 `&page=N`처럼 내용이 같은 페이지는 1개만 분석한다.
- 순서는 게시글 상세를 먼저 꺼내는 우선순위 BFS다. 무한 URL은 버리지 않고 큐 뒤로 미룬다.
- iframe:
  - `page.frames`로 cross-origin·중첩·srcdoc·about:blank까지 접근한다.
  - lazy iframe은 스크롤하고, 프레임마다 타임아웃을 건다.
  - location의 src는 `frame.url`이 아니라 **iframe 요소의 src 속성을 절대화한 값**이다.
  - iframe으로만 닿는 URL은 단독으로 출력하지 않는다.
- Shadow DOM: closed root는 `add_init_script`로 `attachShadow`를 open 모드로 강제한다.
- location: finder 기본 출력(자손 결합자, id)은 모집요강 형식과 다르므로 형식을 바꿔서 쓴다. `tbody` 자동 삽입 때문에 렌더링 DOM과 원본 HTML 양쪽에서 유일한지 검증한다.
- 쓰기 동작 링크(삭제, 로그아웃, 글쓰기)는 따라가지 않는다.

## 5. 실행 환경 (상세는 05)

- 스택: **Python 3.12 + Playwright(테스트한 버전으로 고정) + Chromium headless shell 동봉(Edge 예비) + PyInstaller 6 onedir(UPX 끔) + 로컬 웹 UI(127.0.0.1, Edge `--app` 창) + 선택적 OpenAI(.env)**
- Edge를 먼저 쓰지 않는 이유: `RemoteDebuggingAllowed` 정책이 꺼져 있으면 Playwright가 쓰는 pipe 연결까지 막힌다. PC마다 Edge 버전도 다르다.
- 결과 파일은 실행 파일 폴더에 UTF-8(BOM 없음)로 쓴다. Windows 기본 인코딩이 cp949이므로 명시한다. 임시 파일에 쓴 뒤 이름을 바꿔 원자적으로 저장한다.
- 시간 측정 구간: "탐지 시작" 클릭부터 시작한다. "탐지 완료"는 `result.json`을 다 쓴 다음 표시한다.
- 제출본은 약 200MB라 이메일 첨부가 안 된다. 대용량 링크로 내고, 접수 방법만 주최 측에 확인한다. 미서명 exe라 사용설명서 첫 장에 SmartScreen "추가 정보 → 실행" 안내를 넣는다.
