- 할 일: 언어·헤드리스 브라우저·Windows 패키징 방식 결정, AI 사용 범위 결정
- 완료 조건: 빈 exe가 Windows 11에서 URL을 입력받아 빈 result.json을 생성

## 결정 (2026-10-14)

| 영역 | 결정 | 근거 |
|---|---|---|
| 언어 | Python 3.12 | research/05 |
| 브라우저 | Playwright 1.64.0 고정 + Chromium headless shell을 exe 옆 `browsers/`에 동봉, 실패 시 Edge(`msedge`) | 기관 PC 정책으로 Edge 원격 디버깅이 막혀도 실행 (05 §3) |
| 패키징 | PyInstaller 6.22.3, onedir, UPX 끔 | 백신 오탐·경로 문제 최소화 (05 §3) |
| UI | 표준 라이브러리 HTTP 서버(127.0.0.1) + Edge `--app` 창 (todo/06에서 구현) | GUI 프레임워크 없이 패키징 단순 (05 §7) |
| AI | 기본 꺼짐. Jev는 실험 후 `.env`로 선택 연결 (research/07) | `eval` 통과는 규칙만으로 해야 함 |
| 런타임 의존성 | `playwright` 하나. 정규화는 `unicodedata` + 자체 표 | exe 용량·수집 누락 위험 최소화 |
| 빌드 | GitHub Actions `windows-latest`에서 매 push마다 빌드 + 한글·공백 경로에서 S0 스모크 테스트, 결과물은 artifact. 최종 확인은 실제 Windows 11 PC | Mac에서는 Windows exe 빌드 불가 |
| 저장소 | 비공개 (제출 전 아이디어 보호, 블라인드 정답 보호). 제출 후 공개 여부 재결정 | 모집요강 "공개된 아이디어는 법적 보호 불가" |

골격: `app/main.py` (URL 입력 → 동봉 Chromium으로 열기 → 빈 `result.json`을 exe 폴더에 UTF-8(BOM 없음)으로 원자적 저장)
