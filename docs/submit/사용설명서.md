# adGuard 사용설명서 (v1.0.0)

## 첫 장: 심사·실행에 꼭 필요한 정보

| 항목 | 내용 |
|---|---|
| 실행 파일 | `adguard\adguard.exe` (압축을 풀고 실행. 설치 필요 없음) |
| 결과 파일 위치 | **`adguard.exe`와 같은 폴더**에 생긴다. 다른 위치에 만들지 않는다 |
| `result.json` | 적격평가용 결과 (붙임4 표준 스키마, UTF-8 BOM 없음). 검출이 없으면 `"findings": []` |
| `result_extra.json` | 4종 밖 추가 탐지 결과 (`technique: "ETC"`, `extra_finding`: `VISIBLE_AD`, `INVISIBLE_CHAR`) |
| 그 밖의 파일 | `report.html`(보고서), `result.csv`(Excel), `history.json`(최초 발견일), `status.json`(조치 상태), `records\`(점검 기록), `logs\`(진행 기록) |
| 검출 시간 | 화면에서 **"탐지 시작"을 누른 때부터 "✔ 탐지 완료 · n초"가 뜨는 때까지**. 이 시점에 `result.json` 저장이 끝난다. 그 뒤의 "증거 화면 캡처·보고서 작성"은 탐지 시간에 들어가지 않는다. `result.json`의 `meta.elapsed_sec`도 같은 구간이다 |
| 상용 AI API | **사용하지 않는다.** `.env`·API KEY가 필요 없고, 외부로 보내는 데이터가 없다 (판정은 규칙 기반) |
| 인터넷 | 점검 대상 사이트에만 접속한다. 외부 서버·클라우드를 쓰지 않는다 |
| 실행 환경 | Windows 11, GPU 없는 일반 PC(CPU·RAM), 메모리 사용 약 1.4~1.8GB |

### Windows 보안 경고가 뜰 때

- 서명하지 않은 실행 파일이라 처음 실행할 때 "Windows의 PC 보호" 창이 뜰 수 있다. **"추가 정보" → "실행"**을 누른다
- 압축 파일을 인터넷에서 받았다면 압축을 풀기 전에 zip 파일 속성에서 "차단 해제"를 체크하면 경고가 줄어든다

## 1. 점검하기 (창 모드)

1. `adguard.exe`를 더블클릭한다
2. 점검할 누리집 주소(예: `https://www.example.go.kr`)를 넣고 **"탐지 시작"**을 누른다
   - "시간 상한"(기본 20분, 1~30분): 이 시간이 지나면 그때까지의 결과로 마친다
3. 진행 화면에서 살펴본 페이지 수, 남은 대기 주소, 검출 수, 경과 시간을 본다
   - **"중단"**을 누르면 진행 중인 페이지만 마치고 그때까지의 결과를 저장한다
4. **"✔ 탐지 완료 · n초"**가 뜨면 탐지와 `result.json` 저장이 끝난 것이다. 이어서 보고서에 넣을 증거 화면을 찍는다 (수십 초~수 분)
5. 결과 화면이 열린다

## 2. 명령줄 모드

| 명령 | 동작 |
|---|---|
| `adguard.exe <URL>` | 창 없이 탐지하고 결과 파일·보고서를 쓴다 |
| `adguard.exe --no-report <URL>` | 탐지와 `result.json`·`result_extra.json`만 쓰고 끝낸다 (보고서·캡처 생략) |

## 3. 결과 화면 읽기

- **요약**
  - 광고 문구 수와 위치 수, 위험도 비율(심각·위험·참고), 기법별 위치 수, 검출이 많은 페이지를 보여 준다
  - 심각은 해킹 삽입 의심이다. 여러 페이지의 같은 위치에 같은 숨김 광고가 반복되는 경우다
- **지난 점검 대비**: 같은 사이트를 전에 점검했으면 다음 네 가지를 센다
  - 새로 발견
  - 계속 있음
  - 조치했는데 다시 나타남
  - 사라짐
- **검출 목록**
  - 같은 광고 문구는 한 항목으로 묶는다. 검색, 위험도·기법·조치 상태 필터, 정렬을 쓸 수 있다
  - 항목을 누르면 다음이 나온다
    - 증거 화면: 숨김 해제 전·후를 겹쳐 보고 막대로 비교한다
    - 숨김·변형 방법과 광고 근거(바꾼 글자 코드, 풀어 읽은 문장, 키워드)
    - 페이지 주소와 요소 위치(CSS 선택자, 복사 버튼)
    - 찾아간 경로(sitemap·클릭 등)
    - 조치 방법
    - 조치 상태
- **사이트 지도**: 살펴본 모든 페이지와 검출 있는 페이지
- **조치 안내**: 게시물형·해킹 삽입 의심·검색엔진 흔적·내부 검색 악용별 처리 절차

| 기법 | 뜻 |
|---|---|
| 유사 문자 치환 (HOMOGLYPH) | 키릴·전각·수학 문자, 한자·숫자처럼 닮은 글자로 바꿔 필터를 피함 |
| 자모 분리 (JAMO) | `ㅋㅏㅈㅣㄴㅗ`처럼 음절을 자모로 쪼갬 |
| 투명·배경색 숨김 (TRANSPARENT) | 배경과 같은 글자색, `opacity:0`, `color:transparent` 등 |
| 화면 밖·크기 0 숨김 (OFFSCREEN) | `font-size` 0~1px, `left:-9999px`, `display:none` 등 |
| 추가 유형 | 그대로 보이는 광고(VISIBLE_AD), 보이지 않는 문자 삽입(INVISIBLE_CHAR) |

## 4. 조치 관리

1. 항목을 펼쳐 "조치 상태"를 고르고 메모를 쓴 뒤 **"저장"**을 누른다
   - 상태: 미조치, 조치 요청, 조치 완료, 오탐(예외)
2. 상태는 `status.json`에 남아 다음 점검에도 이어진다. "조치 완료"로 둔 광고가 다시 나타나면 **재발**로 표시한다
3. "결과 파일" 메뉴
   - **보고서**(`report.html`): 인쇄·PDF 저장용. 인쇄하면 모든 상세가 펼쳐진다
   - **Excel**(`result.csv`): 상태·메모 열이 들어 있다
   - **제출 파일**(`result.json`)
   - **결과 폴더 열기**
4. 오른쪽 위 기록 버튼: 지금까지의 점검 목록. 누르면 그때 결과 화면을 연다

## 5. 문제 해결

| 증상 | 확인할 것 |
|---|---|
| "시작 주소를 열지 못했습니다" | 주소 오타, 사이트 접속 여부, 이 PC에서 브라우저로 열리는지 |
| 창이 뜨지 않음 | WebView2 런타임이 없으면 기본 브라우저로 같은 화면을 연다 (`127.0.0.1` 주소) |
| 결과 파일이 안 생김 | exe 폴더에 쓰기 권한이 있는지 (Program Files 같은 보호 폴더 밖에 압축을 푼다) |
| 오류 원인 | `logs\날짜.log`의 진행 기록 |
