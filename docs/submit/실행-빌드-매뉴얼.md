# adGuard 실행·빌드 매뉴얼 (v1.0.0)

## 1. 구성

| 경로 | 내용 |
|---|---|
| `app/main.py` | 진입점. 창 모드(pywebview + WebView2)와 명령줄 모드, `result.json` 작성 |
| `app/crawler.py` | 탐색: Playwright Chromium으로 하위 페이지·게시글·댓글·iframe 렌더링 |
| `app/detect.py` | 숨김 판정(OFFSCREEN·TRANSPARENT), 후보 수집, location 생성 |
| `app/textcheck.py` | 문자 판정(HOMOGLYPH·JAMO)과 광고성 판정 (브라우저 없이 텍스트만) |
| `app/ai.py` | AI 광고성 판정 (선택, OpenAI Decisions API): 경계 후보만 묻고 마스킹·캐시·호출 상한, 실패하면 규칙 판정 |
| `app/extra.py` | 사이트 진단 (보고서 모드): 검색 노출 위험(ISAP), 검색봇 클로킹 비교 |
| `app/preview.py` | 개발용 디자인 미리보기 (마지막 `report.html` 데이터를 `ui.html`에 끼워 띄움, 실행 파일에는 쓰이지 않음) |
| `app/report.py` | 보고서·CSV·점검 기록·조치 상태·증거 캡처 |
| `app/data/` | 화면(`ui.html`), 글꼴(`adguard-sans.woff2`, Pretendard GOV 부분 글꼴), 닮은꼴 표(`confusables_ascii.tsv`), 제3자 고지 |
| `eval/` | 자체 평가: 테스트 사이트(S0~S8)·정답표·채점기 |

- 런타임 의존성은 `playwright==1.64.0`, `pywebview==6.2.1` 두 개뿐이다
- 빌드할 때만 `pyinstaller==6.22.3`이 더 필요하다

## 2. 소스에서 실행 (Windows·macOS)

준비: Python 3.12 이상.

```bat
python -m venv .venv
.venv\Scripts\activate          (macOS: source .venv/bin/activate)
pip install -r requirements.txt
python -m playwright install chromium

python app\main.py                       :: 창 모드
python app\main.py <URL>                 :: 명령줄 모드
python app\main.py --no-report <URL>     :: 탐지와 결과 파일만
```

- 소스 실행 때는 결과 파일이 `app\` 폴더에 생긴다

## 3. Windows 실행 파일 빌드 (로컬)

준비: Windows 10/11, Python 3.12, 인터넷.

```bat
pip install -r requirements.txt -r requirements-build.txt
pyinstaller --noconfirm --onedir --noupx --name adguard --add-data "app/data;data" app/main.py
set PLAYWRIGHT_BROWSERS_PATH=dist\adguard\browsers
python -m playwright install --only-shell chromium
copy app\.env.example dist\adguard\.env.example
copy app\data\THIRD_PARTY_NOTICES.txt dist\adguard\THIRD_PARTY_NOTICES.txt
powershell Compress-Archive -Path dist\adguard -DestinationPath adguard.zip
```

- 결과물은 `dist\adguard\` 폴더 전체다: `adguard.exe`, `_internal\`, `browsers\`, `.env.example`, `THIRD_PARTY_NOTICES.txt`
  - `adguard.zip`은 이 폴더를 `adguard\` 폴더째 묶은 것이다
  - **`dist\adguard`에서 exe를 실행하지 않는다.** 실행하면 `.env`(키)·`cache\`·`result.json`·`history.json` 등이 생겨 zip에 같이 들어간다. 시험은 다른 폴더에 복사해서 한다
- **onedir로 빌드한다.** onefile은 실행할 때마다 임시 폴더에 풀어 느리고, 백신 오탐이 잦다
- **UPX를 끈다(`--noupx`).** 압축된 실행 파일은 백신 오탐이 잦다
- `browsers\`에 넣은 Chromium headless shell을 우선 쓴다
  - `main.py`가 실행할 때 `PLAYWRIGHT_BROWSERS_PATH`를 exe 옆 `browsers`로 정한다
  - 이 Chromium이 막히면 PC의 Edge로 대신한다

## 4. 자동 빌드 (GitHub Actions)

- `.github/workflows/windows-build.yml`이 push할 때마다 위 3단계를 windows-latest에서 실행한다
- 이어서 다음을 확인한다
  1. 한글·공백이 든 경로(`C:\테스트 폴더\adguard`)로 복사
  2. S0 테스트 사이트를 띄워 명령줄 모드와 WebView2 창 모드 실행
  3. `eval/validate.py`로 스키마 검사
  4. S1 테스트 사이트를 exe로 점검하고 채점해 재현율·정밀도 100%인지 확인 (탐지 회귀)
  5. 배포 폴더에 실행 산출물(`.env`·결과 파일 등)이 없는지 확인하고 `adguard.zip`과 SHA-256(`adguard.zip.sha256.txt`)을 만든다
- 결과물은 Actions 실행 페이지의 artifact `adguard-windows`에서 받는다. 받은 파일을 풀면 `adguard.zip`과 `adguard.zip.sha256.txt`가 나온다

## 5. 빌드 확인 (제출 전)

1. 깨끗한 Windows 11에서 zip을 한글·공백이 든 경로에 풀고 `adguard.exe`를 실행한다
2. 자체 테스트 사이트로 점검하고 채점한다

```bat
python eval\scenarios\S1-baseline\serve.py
adguard.exe --no-report http://127.0.0.1:8110/
python eval\scorer\score.py S1-baseline result.json
python eval\validate.py result.json
```

3. 시나리오 목록·포트·채점 규칙은 `eval/README.md`에 있다
4. 백신으로 zip과 exe를 검사하고 SHA-256을 기록한다

```bat
certutil -hashfile adguard.zip SHA256
```

## 6. 설정값

| 값 | 위치 | 기본 |
|---|---|---|
| 시간 상한 | 화면 "시간 상한" (5~25분, 보고서 작성까지 포함) | 20분 (명령줄 모드도 20분) |
| 병렬 수 | `crawler.py` `Crawler.workers` | CPU 수에 맞춰 2~6. 서버가 버거워하면 자동으로 줄인다 |
| 같은 형태 주소 상한 | `crawler.py` `CAP_PATTERN`·`CAP_HARD`·`CAP_DATE` | 500 넘으면 뒤로 미룸, 3000에서 버림. 날짜형은 24 |
| 캡처 상한 | `report.py` `SHOT_MAX`·`SHOT_SEC` | 100묶음, 240초 |
