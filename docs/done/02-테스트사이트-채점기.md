- 채점기 `eval/scorer/score.py`: 서버 자동 기동, location을 렌더링된 요소로 비교(iframe src 절대화, Shadow DOM 호스트 `>>>` 지원), 중복 통합, 스키마 위반 항목은 오답, 오탐 사유 분류, 배점 환산, 통과 기준 O/X. 블라인드는 숫자만 출력
- 고친 것: S2 정답표에 같은 미끼가 다른 표기로 두 번 들어가 있어 하나 삭제. 자기 검증의 중복 케이스는 id가 같으면 스키마 위반이므로 id를 다르게 생성
- **블라인드 노출 기록:** 채점기 첫 실행 때 블라인드 정답표 오류 메시지로 location 1개(`div#host-open …`, Shadow DOM 호스트를 `>>>`로 지나는 표기)가 개발자에게 보였다. 이후 블라인드 오류는 id만 출력하도록 막음. 블라인드 결과는 이 노출을 감안해서 본다
- 시간 점수는 탐지 결과와 무관하게 elapsed_sec만 본다 (모집요강 기준). 빈 결과도 시간 20점이 나온다
