# 실제 사이트 대응

- 할 일: 테스트 사이트가 아닌 실제 공공 웹사이트에서 크롤러가 멈추거나 놓치는 경우를 찾아 대비한다
- 완료 조건: 실제 사이트 3곳에서 오류 없이 꾸준히 탐색, 테스트 시나리오 S1~S5 점수·시간 그대로

## 방법 (2026-10-15)

- Google `site:go.kr`·`site:ac.kr` + 도박 키워드로 불법광고 게시 이력이 있는 공공 사이트를 찾고, 그누보드 게시판 3곳(아래 A·B·C)을 3분씩 돌렸다
- 남의 서버이므로 사이트별로 몇 번만 돌렸다. 기관명은 문서·발표에서 가린다
- 진단: 페이지 열기·클릭 탐색 단계별 시간, 끝나지 않은 요청 목록, 오류 종류를 찍는 임시 스크립트

## 발견한 문제와 대응

| 상황 | 증상 | 원인 | 대응 |
|---|---|---|---|
| 끝나지 않는 요청이 세션을 잠금 | A: 메인 1쪽 뒤 모든 페이지 15초 타임아웃, 25쪽 방문에 결과 7쪽 | 클릭 탐색이 SNS 공유 버튼(`sns_send.php`)을 눌렀고 그 요청이 끝나지 않음. PHP는 같은 세션 요청을 하나씩 처리하므로 같은 쿠키의 요청이 모두 대기 | 공유 주소(`sns_send`, `sharer.php`)를 위험 주소에 넣고, 버튼으로 나가는 요청(새 창 포함)도 컨텍스트에서 차단. 연결 실패·타임아웃이면 쿠키가 새로운 컨텍스트로 교체 |
| 동시 접속에 약한 서버 | A: `ERR_CONNECTION_TIMED_OUT`이 이어짐 | 서버가 동시 요청을 감당하지 못함 (1개씩 열면 0.5초) | 연결 실패이거나 연속 실패일 때 그 주소를 나중에 1번 더 시도. 연속 3번 실패하면 병렬 수를 절반으로, 10번 성공하면 1씩 늘림 |
| 모바일 전용 게시판 | A: 입력한 게시판 주소가 결과에 없음 | PC 화면으로 열면 "모바일 전용입니다" 경고창 뒤 메인으로 보냄 | 경고창 문구에 모바일·mobile·스마트폰이 있고 다른 주소로 보내지면 모바일 화면(iPhone 13 에뮬레이션)으로 다시 연다. 같은 게시판(글 번호·쪽 번호를 뺀 주소)의 다른 글은 처음부터 모바일로. 증거 캡처도 모바일 화면으로 찍는다 |
| 경고창·확인창 | A·B·C: "로그인 후 사용", "잘못된 접근입니다" 등 | 권한·잘못된 주소 안내 | 문구를 진행 기록에 남기고 닫은 뒤 계속 탐색 |
| 첨부파일 내려받기 주소 | B: 다운로드 주소 42번 방문, 그중 5번 "Download is starting" 오류 | `download.php` 같은 주소를 페이지로 열었음 | 내려받기 주소(`download.php/.do/.jsp/.asp`, `filedown`)는 큐에 넣지 않음 |
| 같은 글의 PC/모바일 주소 | A: `&device=pc`, `&device=mobile`이 다른 페이지로 쌓임 | 그누보드 화면 전환 꼬리표 | `device`를 정렬·검색 꼬리표와 같이 제거 |

## 결과 (3분 제한, 병렬 6)

| 사이트 | 수정 전 | 수정 후 |
|---|---|---|
| A (지자체 박물관, 그누보드, 모바일 전용 게시판) | 결과 6쪽, 타임아웃 41건, 입력한 게시판 누락 | 결과 43쪽(모바일 22쪽), 오류 0건 |
| B (지자체 평생학습관, 그누보드) | 결과 123쪽, 다운로드 오류 5건 | 결과 127쪽, 오류 0건 |
| C (대학 사업단, 그누보드) | - | 55초에 94쪽 전부, 오류 0건 |

- A는 병렬 1과 병렬 6의 처리량이 같다(3분 43쪽). 서버가 요청을 하나씩 처리하는 것으로 보이며 병목은 서버다
- 테스트 시나리오: S1~S5 모두 100점, 시간 변화 없음 (S3 40초)

## 결정

- 대비책은 문제가 감지될 때만 작동한다. 오류가 없으면 지금 속도 그대로 (적격평가 검출 시간 20점 보호)
- 혼자 응답하지 않는 함정 페이지(S3 180초 무응답)는 다시 기다리지 않는다. 처음에는 모든 타임아웃을 재시도했다가 S3가 40초에서 55초로 늘어 "연결 실패 또는 연속 실패"로 좁혔다
- 모바일 판정은 경고창 문구 + 리다이렉트가 함께 있을 때만. 로그인 경고는 모바일로 열어도 소용없어서 재시도하지 않는다

## 남은 것

- 보이는 그대로 쓴 도박 광고 글(변형·숨김 없음)은 필수 4종에 들지 않아 검출 대상이 아니다. 추가 탐지(todo/08)에서 다룬다
- 로그인 경고로 못 본 페이지 수를 보고서에 보여 주기 (실무 활용성)
