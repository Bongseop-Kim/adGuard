## 결정

- **P4는 바꾸지 않았다.** `ㅋr지노`는 JAMO + HOMOGLYPH 2건으로 낸다 (research/02·04, eval F12의 기존 결정). research/13 §3의 "다른 문자 체계가 끼면 HOMOGLYPH만" 원칙으로 바꾸려면 S1~S3 정답표의 F12 항목도 함께 고쳐야 한다
- 정상 숨김 지문 목록(sr-only·sound_only 클래스, clip 지문, 닫힌 탭)은 넣지 않았다. "보이는 곳에 같은 글"만으로 A·D 오탐이 사라졌고, 지문은 스패머도 쓸 수 있어 단독으로는 못 쓴다
- 캡처 WebP는 보류: CDP로 찍으면 Playwright의 작성자 가림(mask)을 잃는다. 범위를 줄인 것만으로 60% 줄었다
- AutoThrottle(지연 기반 병렬 조절)은 보류: 실패 원인 기록을 먼저 넣었고, 기록을 모아 본 뒤 판단한다
