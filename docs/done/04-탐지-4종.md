## 결정

- 후보 = 텍스트를 직접 가진 요소(+ input value). 숨김 신호가 있거나 특이 문자가 있는 것만 Python으로 넘긴다
- OFFSCREEN: 렌더링 안 됨, font-size ≤ 1px, 글자 박스 0·높이 3px 미만·글자당 폭 1.5px 미만, 문서 왼쪽·위쪽 밖, 조상 클리핑(overflow·clip·clip-path, absolute/fixed 포함 블록 규칙). 크기 2px 미만 상자는 스크롤 확장보다 먼저 숨김. 한 줄이라도 높이 35% 이상 보이면 보임
- TRANSPARENT: visibility, 누적 opacity·filter:opacity < 0.1, 글자 채움색 알파 < 0.1(그림자·외곽선 없을 때), 조상 배경 합성 후 WCAG 대비 < 1.25. 배경 이미지·그라데이션·blend·background-clip:text는 글자만 숨긴 스크린샷과 비교(차이 > 24 픽셀이 1% 미만이면 안 보임). PNG는 표준 라이브러리로 디코드
- marquee: 300ms 간격 8번 측정해서 한 번도 상자 안에 안 들어오면 OFFSCREEN
- iframe: 접두어 `iframe[src="절대URL"]`(`.src`끼리 비교, 같은 src가 여럿이면 상위 경로), srcdoc은 일반 경로. iframe 요소가 숨겨져 있으면 안쪽 모든 요소에 상속
- location: 태그 + 첫 안정 클래스(없으면 id, 없으면 `:nth-of-type`), 아래부터 올라가며 고유해지면 멈춤. 각 단계에서 클래스만으로 안 되면 순번을 붙여 본다. tbody·thead는 자손 결합자로 건너뜀. Shadow DOM은 `호스트 >>> 안쪽`. 해시·상태 클래스 제외(`e1z9p`처럼 글자·숫자가 섞인 4~8자 토큰 포함)
- 기법마다 1건. 같은 기법이 자손 요소에서도 나오면 부모 것은 뺀다(가장 안쪽 요소). display:none 루트가 광고만 감싸면 루트도 OFFSCREEN으로 낸다
- 문자 판정
  - 정규화: 한글 계열은 NFKC를 쓰지 않는다(자모가 음절로 미리 합쳐져 흔적이 사라짐). 나머지는 NFKC + 결합 부호 제거, 첫가끝·반각 자모 → 호환 자모, 자체 조합기
  - HOMOGLYPH: 전각·수학·원문자 토큰, 라틴을 닮은 다른 문자 체계(confusables.txt에서 ASCII 1글자로 가는 1,586자), 한글 옆 닮은 한자·가나·숫자, 자모 옆 라틴·숫자를 한글로 읽으면 새 키워드, leet, 결합 부호
  - JAMO: 자모 조합 음절 2개 이상(또는 1개 + 새 키워드), 초성 약어(연락처·코드가 함께 있을 때), 받침 노이즈(3음절 이상 키워드)
  - 광고성: 범주 키워드 1개 이상 AND (연락처·코드·보너스% 또는 키워드 2개 또는 행동 유도어). 부정 문맥(예방·신고·단속 등)이 있으면 연락처가 있을 때만. 기관 도메인(`go.kr` 등)·이메일은 연락처가 아님
